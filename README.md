# 中国城市地铁步行 1 公里覆盖地图

本项目以 SVG 地图展示中国城市的地铁步行覆盖范围。地图沿步行路网计算到最近运营地铁站出入口的最短步行距离，并标出距离不超过 **1 公里** 的区域。

例如，某处离站口直线距离为 800 米，但沿路需要走 1.2 公里，就不计入覆盖范围。

## 怎样读图

- **珊瑚红色块**表示按 8 米网格估算的步行覆盖范围。
- **深红色线条**表示沿步行路网走到地铁出入口不超过 1 公里的路段。
- **行政区界**用于定位和对照各区的覆盖情况。

SVG 可以在浏览器中打开和放大。如果 GitHub 无法预览，可以下载后查看。

## 数据与精度

步行路网主要来自 OpenStreetMap。部分站口与路网之间的接驳距离采用估算，未记录的小路、过街通道或门禁可能影响局部覆盖边界。具体数据来源以各地图上的标注为准。[OpenStreetMap 版权与 ODbL 许可](https://www.openstreetmap.org/copyright)
